# Security Policy

## Reporting a vulnerability

Do not publish credentials, exploit payloads, private datasets, or sensitive research artifacts in a public issue.

If GitHub private vulnerability reporting is available, use it. Otherwise contact the repository owner privately through GitHub and provide the minimum non-destructive reproduction information needed.

Security testing does not authorize access to brokerage accounts, financial accounts, third-party APIs, live trading systems, or systems you do not own.

## Project boundary

Project 9 is a research-first paper/simulation environment. Security changes must not silently add real-money order execution, brokerage connectivity, or claims of profitable live-trading performance.
